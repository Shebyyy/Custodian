# Custodian — Discord Server Utility Bot

A Discord bot with 4 modules: Channel Backup, Member Tracking, Verification + Quiz Gate, and Restore.

## Quick Start

```bash
cd discord-bot
bun install
cp .env.example .env
```

Edit `.env` — put your bot token:
```
DISCORD_BOT_TOKEN=your_token_here
```

Then:
```bash
bun run db:setup    # Create database tables
bun run dev         # Start the bot
```

## How to Create the Bot

### 1. Discord Developer Portal
Go to https://discord.com/developers/applications → New Application → Name it **Custodian**

### 2. Get Token
Bot → Reset Token → Copy → Paste in `.env`

### 3. Enable Intents (required)
Bot page → Privileged Gateway Intents → Turn ON:
- ✅ Server Members Intent
- ✅ Message Content Intent
- ✅ Presence Intent

### 4. Invite to Server
OAuth2 → URL Generator → Check **bot** scope → Check these permissions:

| Permission | Why |
|-----------|-----|
| Send Messages | DM members, post messages |
| Read Message History | Read all messages for backup |
| Embed Links | Rich embeds |
| Attach Files | Export backups as files |
| Manage Messages | Control message flow |
| Manage Channels | Create webhooks for restore |
| Create Instant Invite | Generate invite links |
| Manage Roles | Assign/remove roles |
| Manage Webhooks | Restore under original author names |
| Use Application Commands | Slash commands |
| Add Reactions | Reaction tracking |

Copy the URL → open it → pick your server → Authorize

### 5. Create Roles in Discord
Server Settings → Roles → Create:

| Role | Purpose |
|------|---------|
| **Unverified** | New members — restricted access |
| **Verified** | Passed quiz — full access |
| **Admin** | Can use bot commands |

### 6. Run /setup in Discord
Type `/setup` in any channel. The bot will walk you through picking roles and channels using dropdown menus. Everything gets saved automatically.

## Commands

### Setup
| Command | Description |
|---------|-------------|
| `/setup` | Setup wizard — pick roles, channels, backup via dropdowns |

### Module 1 — Channel Backup
| Command | Description |
|---------|-------------|
| `/backup-add` | Start backing up a channel (pick from menu) |
| `/backup-remove` | Stop backing up a channel |
| `/backup-list` | Show all backed up channels |
| `/backup-export` | Export backup as JSON file |

### Module 2 — Member Tracking
| Command | Description |
|---------|-------------|
| `/members-stats` | Total, active, left member count |
| `/migrate-invite` | DM every stored member an invite link (rate-limited) |
| `/migrate-report` | How many DMs sent/failed/joined |

### Module 3 — Verification
| Command | Description |
|---------|-------------|
| `/verify-stats` | Verified, pending, failed, flagged counts |
| `/verify-manual` | Manually verify a user |
| `/verify-flagged` | View users who failed 3 times |

### Module 4 — Restore
| Command | Description |
|---------|-------------|
| `/restore-map` | Map old channel → new channel (pick from menus) |
| `/restore-unmap` | Remove a mapping |
| `/restore-list` | Show all mappings |
| `/restore-preview` | Dry run — shows what would be posted |
| `/restore-run` | Restore messages (rate-limited) |

## Folder Structure

```
discord-bot/
├── .env.example              # Token template
├── .env                      # Your token (never commit)
├── .gitignore
├── package.json
├── tsconfig.json
│
├── config/
│   └── bot.config.json       # Auto-generated by /setup (roles, channels, quiz)
│
├── data/
│   └── bot.db                # SQLite database (auto-created by db:setup)
│
└── src/
    ├── index.ts              # Entry point — registers all commands
    ├── db.ts                 # Database connection
    ├── db-setup.ts           # One-time table creation
    ├── config.ts             # Reads .env + bot.config.json
    ├── utils.ts              # Helpers
    │
    ├── commands/
    │   └── setup.ts          # /setup wizard with Discord dropdowns
    │
    └── modules/
        ├── channel-backup.ts # Module 1
        ├── member-tracking.ts # Module 2
        ├── verification.ts   # Module 3
        └── restore.ts        # Module 4
```

## What Goes Where

| File | Contents | Secret? |
|------|----------|---------|
| `.env` | Bot token only | 🔴 YES |
| `config/bot.config.json` | Roles, channels, quiz, rules (auto-generated by /setup) | 🟢 NO |
